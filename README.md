# Vyom Jain – Portfolio

A modern, responsive portfolio website built with vanilla HTML/CSS.

Live site: https://vyom1jain.github.io/portfolio/

Features:
- Clean, modern UI with glassmorphism and subtle animations
- Responsive layout for mobile, tablet, and desktop
- Project cards, skills grid, and contact links

Getting started:
- Edit index.html to update content
- Tweak styles in style.css

Built and deployed via GitHub Pages from the main branch.

## Projects

### Task Management System

A modern, fully-functional task management web application built with vanilla HTML, CSS, and JavaScript.

**Live Demo:** [https://vyom1jain.github.io/portfolio/task-management-system/](https://vyom1jain.github.io/portfolio/task-management-system/)

**Features:**
- ✅ Add, edit, delete tasks
- ✅ Mark tasks as complete/incomplete
- ✅ Filter tasks (All, Active, Completed)
- ✅ Task statistics dashboard
- ✅ Persistent storage using localStorage
- ✅ Responsive design for mobile and desktop
- ✅ Modern, clean UI with smooth animations

**Tech Stack:** HTML5, CSS3, JavaScript (ES6+), localStorage API

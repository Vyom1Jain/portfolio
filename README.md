# Vyom Jain – Portfolio

A modern, responsive portfolio website built with vanilla HTML/CSS.

Live site: https://vyom1jain.github.io/portfolio/

Features:
- Clean, modern UI with glassmorphism and subtle animations
- Responsive layout for mobile, tablet, and desktop
- Project cards, skills grid, and contact links

Getting started:
- Edit index.html to update content
- Tweak styles in style.css

Built and deployed via GitHub Pages from the main branch.
